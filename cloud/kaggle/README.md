# Phase C2 Kaggle Runner

This directory contains the necessary components to run Phase C2 training efficiently on Kaggle using GPUs or CPUs.

## Instructions
1. Create a new notebook on Kaggle.
2. Upload `phase_c2_kaggle.ipynb` to the notebook, or copy its contents.
3. If the repository is private, add a **Kaggle Secret** named `GITHUB_TOKEN` containing your read-only GitHub Personal Access Token. The notebook automatically uses it to clone the repository securely without leaking credentials.
4. Set the parameters in the first cell:
   - `MODEL_TO_RUN`: `"M1"` (Global-Local) or `"M2"` (Scalar-Only)
   - `MAX_INTERACTIONS`: `150000`
   - `RESUME`: `False` (or `True` if resuming from a checkpoint bundle)
5. Run the notebook.

## Resume Instructions
To resume a training session:
1. Ensure `RESUME = True` in the notebook parameters.
2. Upload the `latest_checkpoint_bundle.zip` generated by your previous run to Kaggle as a dataset.
3. Point the notebook to the uploaded dataset path when prompted (or modify the `RESUME_BUNDLE_PATH` variable in the notebook).
4. Run the notebook. The runner will transparently load the model, generator states, curriculum stage, and interactions, reporting them as statistically equivalent.

## Output Structure
Outputs are saved in `/kaggle/working/uav_phase_c2/`:
- `model_{step}.zip`
- `generator_{step}.json`
- `status.json`
- `latest_checkpoint_bundle.zip` (Contains all above for easy recovery)
- `rl_v3_phase_c2_<MODEL>_raw_artifacts.zip` (Final archive)
